## Sobre mim

Sou desenvolvedor de software com foco em Java, desenvolvimento backend e construção de aplicações desktop e web.

Minha formação em tecnologia abrange fundamentos de informática, sistemas operacionais, programação, desenvolvimento de interfaces e bancos de dados. Tenho experiência prática com Java, JPA, Hibernate, SQL e integração entre aplicações.

Busco aprimorar continuamente minhas habilidades, desenvolver soluções bem estruturadas e aprofundar meus conhecimentos em arquitetura de software e desenvolvimento web.

**Áreas de interesse**

- Desenvolvimento backend com Java.
- APIs REST e persistência de dados.
- Aplicações web com Angular e TypeScript.
- Bancos de dados relacionais e serviços em nuvem.
- Boas práticas de programação e organização de projetos.
