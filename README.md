## SOBRE MIM

Desenvolvedor com foco em Java, desenvolvimento backend e aplicações desktop. Tenho experiência no desenvolvimento e na manutenção de sistemas, manipulação de bancos de dados relacionais e construção de interfaces web.

Busco desenvolver soluções organizadas, funcionais e sustentáveis, aplicando boas práticas de programação, separação de responsabilidades e princípios de arquitetura de software.

- Desenvolvimento de aplicações Java.
- Construção e integração de APIs REST.
- Persistência de dados com JPA e SQL.
- Desenvolvimento de interfaces com Angular.
- Versionamento de código com Git e GitHub.
- Aprimoramento contínuo em arquitetura e qualidade de software.
