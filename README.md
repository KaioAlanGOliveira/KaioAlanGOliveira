## SOBRE MIM

Desenvolvedor de software com foco em Java, backend e aplicações desktop e web. Experiência prática no desenvolvimento e na manutenção de sistemas, implementação de regras de negócio, integração com bancos de dados relacionais e construção de interfaces.

Tenho interesse em arquitetura de software, APIs REST, persistência de dados e integração entre aplicações, buscando desenvolver soluções organizadas, funcionais e de fácil manutenção.

- Desenvolvimento backend com Java.
- Construção e integração de serviços REST.
- Persistência de dados com JPA, Hibernate e SQL.
- Desenvolvimento de interfaces web com Angular.
- Aplicações desktop com Java Swing.
- Modelagem de dados e consultas SQL.
- Versionamento e gerenciamento de código com Git e GitHub.

## PROJETOS EM DESTAQUE

Projetos desenvolvidos para aplicar conceitos de programação, persistência de dados, automação, integração de sistemas e desenvolvimento de aplicações.

### 01. WP-CateSys

**Sistema de gestão com frontend Angular e backend Java.**

Projeto voltado à gestão de alunos, professores, turmas, aulas e registros de presença.

**Tecnologias:** Java, Angular, MySQL, JPA e APIs REST.

[ Acessar repositório ](https://github.com/KaioAlanGOliveira/WP-CateSys)

### 02. WP-Login

**Aplicação web com backend Java e frontend Angular.**

Projeto de estudo de endpoints REST, injeção de dependências e integração entre camadas da aplicação.

**Tecnologias:** Java, Jakarta EE, JAX-RS, CDI, JPA, Angular e MySQL.

[ Acessar repositório ](https://github.com/KaioAlanGOliveira/WP-Login)

### 03. Sistema de Cadastro de Fiéis

**Aplicação desktop com persistência relacional.**

Sistema para cadastro e consulta de fiéis e gerenciamento de pagamentos de dízimos, com interface gráfica e operações de manutenção de registros.

**Tecnologias:** Java, Swing, JPA, Hibernate e MySQL.

[ Acessar repositório ](https://github.com/KaioAlanGOliveira/sw_cad_fiel)

### 04. Tool-QrCode

**Gerador de QR Codes para WhatsApp.**

Aplicação desktop que permite informar um número de telefone, personalizar uma mensagem e gerar um QR Code para abrir uma conversa no WhatsApp.

**Tecnologias:** Java, geração de QR Code e integração com links do WhatsApp.

[ Acessar repositório ](https://github.com/KaioAlanGOliveira/Tool-QrCode)

### 05. WhatsApp Bot

**Automação de interações com o WhatsApp Web.**

Projeto de automação para interação com elementos da interface web, localização de contatos e envio de mensagens utilizando automação de navegador.

**Tecnologias:** Java, Selenium WebDriver e automação web.

[ Acessar repositório ](https://github.com/KaioAlanGOliveira/whatsapp-bot)

### 06. Directory Organizer

**Ferramenta para organização automática de arquivos.**

Aplicação que organiza arquivos em diretórios a partir de regras predefinidas, com suporte à definição de origem, destino e critérios de organização.

**Tecnologias:** JavaScript e Node.js.

[ Acessar repositório ](https://github.com/KaioAlanGOliveira/directory-organizer)

### 07. MP-Notificador

**Aplicativo Android para comunicação de grupos de oração.**

Projeto destinado à centralização de avisos, notificações e mensagens religiosas, priorizando a organização das informações e a facilidade de utilização.

[ Acessar repositório ](https://github.com/KaioAlanGOliveira/MP-Notificador)
